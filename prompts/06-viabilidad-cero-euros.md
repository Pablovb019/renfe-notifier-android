# Verificar coste cero

Consulta documentación oficial vigente e indica fecha y enlaces.

Evalúa:
- VM e2-micro existente: región, horas agregadas, disco, IP, tráfico y logs.
- Diferencia entre Free Tier y créditos temporales.
- FCM y Firebase Spark sin facturación vinculada.
- GitHub Actions privado: minutos, almacenamiento, cachés y artefactos.
- Posibilidad de impedir consumo pagado en mi cuenta.
- Acceso cifrado permanente sin dominio de pago.

Distingue condiciones publicadas de configuración real comprobada.
No pidas acceso a secretos ni cambies planes o infraestructura.
No presentes alertas presupuestarias como corte automático del gasto.

Guarda docs/costs.md.
Si no puedes verificar 0 €, identifica el bloqueo de despliegue.
