# Conectar Android con el backend

Implementa:
- Cliente HTTP con validación TLS normal.
- Contratos de la API.
- Emparejamiento.
- Protección de credenciales mediante Android Keystore.
- DataStore para preferencias no secretas.
- Manejo de desconexión, credencial revocada y errores.
- Backend como fuente de verdad.

No marques como guardada una operación remota fallida.
No añadas Room salvo necesidad aprobada.
No aceptes URLs o esquemas inseguros fuera del diseño de conexión.

Prueba con servidor simulado y compila.
