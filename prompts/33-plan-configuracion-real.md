# Proponer configuración real y solicitar permisos

Prepara una lista exacta de acciones necesarias:
- Firebase Spark y permisos FCM.
- Identidad del servidor.
- TLS y acceso Android/backend.
- Acceso administrativo y CD.
- Secretos de GitHub.
- Distribución del APK.
- Mediciones pendientes en VM.

Para cada acción indica recurso afectado, riesgo, coste y reversión.
Revalida las condiciones gratuitas antes de proponer ejecución.
No leas ni muestres valores secretos.

Este paso solo prepara el plan.
Solicita aprobación específica y no ejecutes cambios.
Si persiste un bloqueo de coste cero, no propongas desplegar.
