# Crear aplicación Android mínima

Crea Kotlin/Compose con:
- Un módulo organizado por funcionalidades.
- Versiones estables compatibles de JDK, Gradle, AGP, Kotlin y SDK.
- Compatibilidad con Android 13.
- Activity, navegación y tema claro/oscuro.
- Recursos en español.
- Accesibilidad básica.
- ViewModel y coroutines/Flow.

No uses un targetSdk antiguo para eludir restricciones.
No añadas capas vacías, WebView ni PWA.
Documenta compilación local en Windows.

Compila realmente el APK debug o registra el bloqueo.
