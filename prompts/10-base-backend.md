# Crear backend mínimo

Precondición: arquitectura y CI/CD aprobados.

Crea únicamente:
- Estructura modular mínima.
- Configuración Python y dependencias reproducibles.
- Configuración de tests y análisis estático.
- Arranque y cierre de la aplicación.
- Endpoint de salud sin información sensible.
- Configuración validada mediante variables de entorno.
- Ejemplo de configuración sin valores secretos.

No conectes Renfe, FCM ni producción.
No inicies navegador o planificador.
Ejecuta análisis y una prueba de arranque.
